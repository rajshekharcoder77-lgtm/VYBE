# 🚀 VYBE — Full‑Stack Social Media App (MERN)

VYBE is a modern **full‑stack social media platform** inspired by Instagram and WhatsApp, featuring reels, stories, real‑time chat, and live notifications. Built with the **MERN stack + Socket.IO + Cloudinary + Tailwind CSS**, it demonstrates scalable architecture, secure authentication, and interactive UI/UX.

---

# ✨ Features

* 🎬 **Reels / Shorts** (vertical video feed like Instagram)
* 💬 **Real‑Time Chat** with Socket.IO
* 📸 **Stories** that auto‑delete after 24 hours
* ❤️ **Like / Comment / Post System**
* 🔔 **Live Notifications**
* 👥 **Follow / Unfollow Users**
* 🖼 **Image & Video Upload** via Cloudinary
* 🔐 **JWT Authentication & Protected Routes**
* 📱 **Responsive UI** with Tailwind CSS

---

# 🧱 Tech Stack

## Frontend

* React (Vite)
* Redux Toolkit
* Tailwind CSS
* Axios
* React Router
* Socket.IO Client

## Backend

* Node.js
* Express.js
* MongoDB + Mongoose
* Socket.IO
* JWT Auth
* Cloudinary
* Multer
